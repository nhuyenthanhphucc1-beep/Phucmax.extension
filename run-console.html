🎮 Phucmax Extension - JSON Installer

Chạy tiện ích trực tiếp từ JSON mà không cần tải/giải nén

📌 Cách 1: Dán vào Console (NHANH NHẤT)

Bước 1: Copy đoạn mã dưới đây
Click nút "Copy" để sao chép toàn bộ mã
Bước 2: Mở Console
Vào trang Garena đăng ký → Nhấn F12 → Tab Console
Bước 3: Dán và chạy
Dán mã vừa copy → Nhấn Enter → Extension chạy ngay!
✅ Thế là xong!
Extension sẽ hiện panel bên cạnh, bắt đầu tạo tài khoản tự động

📚 Các cách khác

Cách 2: Clone từ GitHub
Nếu bạn có Git:
git clone https://github.com/nhuyenthanhphucc1-beep/Phucmax.extension.git
Sau đó: Chrome → chrome://extensions/ → Developer mode → Load unpacked
Cách 3: Mở Install Page
https://raw.githubusercontent.com/nhuyenthanhphucc1-beep/Phucmax.extension/main/install.html
Dán link vào browser → Giao diện cài đặt sẽ hiện lên
Cách 4: Thủ công (Nâng cao)
1. Tải extension-bundle.json từ GitHub
2. Chạy: node extract.js
3. Chrome → Load unpacked

❓ Câu hỏi thường gặp

Q: Có an toàn không khi dán code vào console?
A: Có. Code này là open-source, bạn có thể kiểm tra trên GitHub. Nó chỉ tạo extension content script, không truy cập dữ liệu của bạn.
Q: Extension chỉ hoạt động trên trang nào?
A: Chỉ hoạt động trên https://sso.garena.com/universal/register* (trang đăng ký Garena)
Q: Nếu tắt trang đi thì extension có mất không?
A: Cách 1 (console): Có, cần dán lại. Cách 2/3 (Load unpacked): Không, extension sẽ lưu vĩnh viễn.
⚠️ Lưu ý quan trọng
• Chỉ dùng extension này trên tài khoản của riêng bạn
• Garena có thể chặn nếu tạo quá nhiều tài khoản liên tục (đổi IP sau 7 acc)
• Không chia sẻ tài khoản/password được tạo công khai
