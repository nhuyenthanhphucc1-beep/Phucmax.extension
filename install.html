Phucmax Extension
Tạo tài khoản Garena tự động
ℹ️ Hướng dẫn nhanh
Bấm nút bên dưới để tải extension. Sau đó vào chrome://extensions/ và Load unpacked.
1
📥 Tải files
Click nút "Tải Extension" để tải toàn bộ files
2
📂 Giải nén
Giải nén file ZIP vào một thư mục
3
⚙️ Mở Extension Manager
Vào chrome://extensions/
4
🔧 Bật Developer Mode
Bật "Developer mode" ở góc trên phải
5
📦 Load Extension
Click "Load unpacked" → Chọn thư mục extension
✅ Cách dùng
1. Mở trang đăng ký Garena
2. Extension sẽ hiện panel bên cạnh
3. Nhập tên mẫu (VD: phucmax) và bật Tự động
4. Extension sẽ tạo tài khoản liên tục
